## 本次功能与边界

新增可选[私密存储接口 v1](../PRIVATE_STORAGE.md)，需要精确非公开渠道、显式允许和专用 API Token。普通上传、已有公开图片和存储配置保持原行为；未新增 DDL。

首轮仅使用 `cloudreve-test/` 和 Docker 本地 `cfr2:R2_env`，服务端显式配置 `IMGBED_PRIVATE_STORAGE_CHANNELS=cfr2:R2_env` 后才允许私密上传。Cloudreve 采用单实例、独占目录与稳定上传 ID；S3 必须另外确认 Bucket 不公开。

服务器尚未由本次任务升级，真实图床渠道与 Cloudreve 联调仍待用户升级后执行。产生私密文件后，不直接给旧版提供新数据；按运维操作单使用升级前快照恢复到新的专用目录，并保留升级后现场。
