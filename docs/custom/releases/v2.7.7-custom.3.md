## 使用

Cloudreve只配置ImageBed地址、API Token、专用目录；ImageBed沿用自身默认上传类型/名称。现有Telegram不迁移，Telegram无需增加环境变量。普通公开上传、已存图片和旧显式R2/S3私密客户端继续可用。

R2/S3仍需非公开渠道显式许可。Telegram频道/超级群不能有公开用户名，个人私聊允许对方有用户名；频道成员范围由用户控制。Telegram删除沿用原图床逻辑删除，不撤回频道消息或保证物理擦除。详细合同见[统一接口说明](../PRIVATE_STORAGE.md)。

完整备份、升级及恢复按[操作单](https://github.com/haipengTian/server-ops/blob/main/imgbed/PRIVATE_STORAGE_UPGRADE.md)执行。服务器真实升级与Cloudreve联调尚未执行；本轮远端写入仍限cloudreve-test/。不新增DDL，不上传源码包，不直接把私密数据交给不支持协议的旧版。
